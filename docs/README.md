# docs/

Coloca aquí la presentación explicativa de la herramienta
(`presentacion_stakeholder_map.pptx`) y cualquier otro material de apoyo.

Notas:
- GitHub no previsualiza .pptx en línea; los usuarios lo descargan. Si
  quieres una versión visible en el navegador, exporta también un PDF.
- Si el archivo supera 100 MB, GitHub lo rechaza: usa Git LFS
  (`git lfs install && git lfs track "*.pptx"`) antes del commit.
- No incluyas en la presentación capturas con datos reales de stakeholders
  si el repositorio va a ser visible fuera del equipo.
